PAD-AUTO-002: Generador de Resúmenes de Incidencias con IA

Power Automate Desktop (PAD) Power Automate Web Microsoft Teams API ChatGPT Enterprise API / Web Windows Task Scheduler & .bat
🤖 Flujo Activo (2026)
🔒
Nota de Confidencialidad: Debido a que este bot recopila logs y datos confidenciales sobre incidencias internas de clientes y opera sobre los canales oficiales de comunicación de la empresa, el código del flujo y el acceso directo a los repositorios permanecen protegidos bajo NDA. A continuación, se presenta un desglose de la lógica de integración, sincronización temporal y el flujo general de ejecución.

Diagrama de Ejecución y Sincronización

Integración híbrida en la nube y en local para el procesamiento semanal mediante Inteligencia Artificial.

1
⏰

Extracción Automática (Power Automate Web)

Se activa cada domingo a las 23:59h. Llama a la API de Microsoft Teams con el ID del canal "Incidencias" para extraer todo el historial de la semana.

2
💾

Almacenamiento en OneDrive

El flujo en la nube escribe un archivo .txt en una carpeta de OneDrive llamada Incidencias_Semana_[Inicio]_[Fin].txt, conteniendo texto en crudo con código HTML y logs.

3
⚙️

Programación de Tareas & PAD (Lunes 0:10h)

El programador de tareas de Windows ejecuta un script .bat que arranca Power Automate Desktop. Requiere sesión activa de usuario por seguridad y automatización de interfaz de usuario (UI).

4
🧹

Depuración y Limpieza del Fichero

PAD lee el archivo de OneDrive, extrae las fechas para inicializar las variables FechaInicioSemana y FechaFinalSemana, y aplica bloques de Regex para eliminar etiquetas HTML y ruido.

5
🤖

Prompting en ChatGPT Enterprise

PAD abre Microsoft Edge, accede a la versión corporativa de ChatGPT e inyecta un prompt predefinido para clasificar (Graves, Altas, Leves), detallar acciones tomadas, resoluciones y una conclusión.

6
📋

Interacción Humana (OneNote)

El bot finaliza dejando el resumen listo. El usuario copia el resultado con un solo clic y lo pega en el OneNote integrado en Microsoft Teams. ¡Listo para leer en 2 clics!

S

Situación

Bajo una modalidad de teletrabajo intensivo, el canal de soporte técnico de Microsoft Teams registraba decenas de incidencias diarias, soluciones aportadas y comentarios de seguimiento. Anteriormente, los técnicos debían actualizar manualmente un documento de OneNote que sirviera como bitácora y registro estructurado. Por falta de tiempo, la dispersión de los mensajes y la sobrecarga diaria, el OneNote quedó desactualizado. Esto dificultaba la coordinación del equipo y creaba un gran vacío de información para los compañeros que se reincorporaban de vacaciones o bajas médicas.

T

Tarea

Automatizar la recopilación completa, filtrado de ruido técnico, catalogación y generación de un reporte ejecutivo semanal de todas las incidencias comunicadas por Teams. El sistema debía clasificar los casos por nivel de gravedad, documentar si estaban resueltos y qué acciones se tomaron, y dejar el resumen formateado listo para ser insertado en OneNote antes de que el equipo comenzara a trabajar el lunes por la mañana.

A

Acción

Diseñé una arquitectura híbrida de automatización dividida en tres módulos principales:

  1. Extracción en la Nube (Power Automate Cloud): Programé un flujo en la nube ejecutado semanalmente los domingos a las 23:59 PM. Mediante peticiones a la API de Microsoft Graph, extrae el hilo completo de conversaciones del canal "Incidencias" y escribe un archivo de texto plano en OneDrive estructurado con fechas variables en el título.
  2. Automatización del Sistema y Limpieza (PAD + Batch): Configuré una tarea programada en Windows que ejecuta un script .bat los lunes a las 0:10 AM (dando un margen de 11 minutos al flujo anterior). Este script inicia Power Automate Desktop en local sobre una sesión de usuario activa. El bot procesa el archivo de OneDrive, extrae dinámicamente el rango de fechas en variables y depura mediante Regex todo el código HTML de marcado residual.
  3. Procesamiento Inteligente (Edge + ChatGPT): Programé al bot para controlar Microsoft Edge y acceder a la cuenta empresarial segura de ChatGPT. El bot automatiza la interfaz escribiendo un prompt refinado para clasificar la gravedad de los tickets (Graves, Altas, Leves), detallar las soluciones y redactar conclusiones semanales, terminando la ejecución y dejando el contenido listo en el portapapeles del sistema.

R

Resultado

El proceso de documentar el historial de soporte pasó de ser una tarea que consumía horas semanales y que a menudo se omitía, a un proceso automatizado que funciona con tan solo 2 clics. Al arrancar el ordenador el lunes por la mañana, mientras el usuario prepara su entorno de trabajo (2-3 minutos), el bot completa el análisis y le presenta el resumen listo. Esto permite mantener un OneNote con una trazabilidad del 100% de las incidencias, facilitando la reincorporación de personal y asegurando la continuidad del conocimiento técnico de la empresa.

⚙️ Detalles de la Integración Híbrida Cloud & Local

Este proyecto destaca por orquestar herramientas de nube, scripts locales y automatización de interfaz web con inteligencia artificial:

  • Microsoft Graph API (Teams): Extracción directa de logs de chat a nivel de infraestructura cloud.
  • Windows Task Scheduler & .bat: Lanzador automatizado local que sincroniza la ejecución local tras la finalización del flujo en la nube.
  • Procesamiento de Texto en PAD: Algoritmos de eliminación de marcado HTML mediante expresiones regulares y bloques lógicos de texto.
  • Modelos de Lenguaje (ChatGPT Enterprise): Consumo seguro de modelos fundacionales para la extracción de entidades, clasificación y resúmenes ejecutivos sin filtración de datos de clientes.
